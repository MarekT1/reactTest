# React Test

Vite + React + MUI app, intended to run with [DDEV](https://ddev.com/).

## DDEV

From this directory:

```sh
ddev start
ddev launch :5173
```

`ddev start` installs npm dependencies and starts the Vite dev server. The app is at [https://reacttest.ddev.site:5173](https://reacttest.ddev.site:5173).

Useful commands:

```sh
ddev npm run build
ddev npm run lint
ddev logs -s web
```
